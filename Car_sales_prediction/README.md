# Car Sales Prediction (terminal project)

Predicts a used car's selling price from its brand, year, mileage, fuel
type, seller type, transmission, and ownership history, using a
RandomForestRegressor trained on real listing data. Everything runs from
the terminal — no web server, no GUI.

## Getting started (after cloning from GitHub)

Requires Python 3.9+.

**1. Clone and enter the project**

```bash
git clone <your-repo-url>
cd "Car sales prediction"
```

**2. Create a virtual environment**

```bash
python -m venv .venv
```

**3. Activate it**

- Windows (PowerShell):
  ```powershell
  .venv\Scripts\Activate.ps1
  ```
- Windows (cmd.exe):
  ```cmd
  .venv\Scripts\activate.bat
  ```
- macOS / Linux:
  ```bash
  source .venv/bin/activate
  ```

Your prompt should now start with `(.venv)`. The `.venv` folder is not
committed to git (see `.gitignore`) — everyone who clones the repo creates
their own.

**4. Install dependencies**

```bash
pip install -r requirements.txt
```

**5. Train the model**

The trained model isn't committed to git either (it's a large binary you
can regenerate in seconds), so this step is required before predicting:

```bash
python train_model.py
```

This reads `data/car_sales.json`, trains a RandomForestRegressor, prints
test-set MAE and R², and saves the model to `model/car_price_model.joblib`.

**6. Predict a price**

```bash
python predict.py
```

Prompts for brand, year, km driven, fuel, seller type, transmission, and
owner history, then prints the predicted selling price.

When you're done, deactivate the virtual environment with:

```bash
deactivate
```

## Data

`data/car_sales.json` holds 3,574 real used-car listings sourced from the
public CarDekho dataset ("CAR DETAILS FROM CAR DEKHO.csv", mirrored on
GitHub at chandanverma07/DataSets). Each record:

```json
{
  "name": "Maruti 800 AC",
  "brand": "Maruti",
  "year": 2007,
  "selling_price": 60000.0,
  "km_driven": 70000,
  "fuel": "Petrol",
  "seller_type": "Individual",
  "transmission": "Manual",
  "owner": "First Owner"
}
```

### Adding more data

- **Manually, one record at a time:**
  ```bash
  python add_data.py
  ```
- **In bulk, from another CSV with the same columns**
  (`name,year,selling_price,km_driven,fuel,seller_type,transmission,owner`):
  ```bash
  python scripts/csv_to_json.py path/to/other_file.csv
  ```
  Duplicate records (same name/year/km/price) are skipped automatically.

Retrain (`python train_model.py`) after adding data so predictions reflect
the new records.
